Rules

  • One accent: gold, only for the emphasized word in a headline, dates and small highlights. Never gold buttons.
  • Headlines are serif, sentence case, end with a period; the last phrase is the gold accent.
  • Primary button = solid deep ink (inverts in dark mode). Secondary = card with hairline border. Pills for status.
  • Radius: 20-26px cards, 999px buttons/pills, 14px inputs. Hairline borders (--line), soft shadow only on hover.
  • Generous whitespace, max 3 columns, no gradients on UI chrome, no emoji in headings.
  • Dark mode: same tokens, swapped values (ink ↔ paper). Respect the OS setting, remember the toggle.
